Descripción del problema

El servidor está demasiado lento. Los usuarios esperan mucho para abrir archivos y el sistema se congela. Desde

la mañana se ha puesto peor.

Causa encontrada

Un proceso de base de datos consumía de forma anormal los recursos de memoria del servidor.

Solución aplicada

Se detuvo el proceso defectuoso, se reinició el servicio de base de datos y se ajustaron sus parámetros de

memoria.
