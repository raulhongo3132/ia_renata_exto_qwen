Descripción del problema

El ERP se queda pensando cuando queremos guardar facturas. A veces tarda varios minutos y luego marca

error. Solo pasa con las facturas nuevas.

Causa encontrada

Saturación temporal de la conexión entre el servidor de aplicaciones y la base de datos.

Solución aplicada

Se reinició el servicio de aplicaciones y se ajustaron las conexiones disponibles hacia la base de datos.
